# 量化交易回测系统｜双均线策略
本项目为课程小组E作业，基于Python实现双均线量化策略回测，完整覆盖数据、策略、回测、可视化评估全流程。

## 📁 项目目录结构
- `data`：数据模块
  存放标的行情数据、沪深300基准数据，包含数据读取、清洗脚本
- `strategy_signal`：策略信号模块
  双均线策略逻辑，计算均线、生成买入/卖出信号
- `backtest`：回测模块
  回测引擎，模拟账户交易、计算持仓与资金变动
- `evaluation`：评估与可视化模块
  计算策略指标：累计收益率、最大回撤、胜率、夏普比率等，绘制收益曲线
- `report`：汇报材料
  项目汇报PPT

## ⚙️ 运行环境与依赖
- Python >= 3.8
- 第三方库：`pandas`、`matplotlib`

## 📌 运行顺序
1. 运行data模块，读取并加载行情数据
2. 运行strategy_signal模块，生成交易信号
3. 运行backtest模块，执行回测
4. 运行evaluation模块，输出指标与绘图

## 📝 项目说明
采用经典双均线策略，短期均线上穿长期均线为买入信号，短期均线下穿长期均线为卖出信号。以茅台股价为测试标的，沪深300作为对比基准，检验策略收益表现。
